# PRIME TEC — Optimized Edition

All website files are in this single folder. There are no asset/image subfolders.

Performance improvements:
- All photos converted from JPG to WebP.
- Images compressed while preserving visual quality.
- Hero image is preloaded and given high fetch priority.
- Below-the-fold images use native lazy loading.
- Images use async decoding.
- Explicit width and height attributes reduce layout shifts.
- All image paths point directly to files in this same folder.
